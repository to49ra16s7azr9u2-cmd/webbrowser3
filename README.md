# MyHome Browser（自分専用スクロール禁止ホーム画面）

「スマホをロックするアプリ」ではなく、**1日の時間を、自分が本当にやりたいこと
（ギターの練習、読書、その他何でも）に取り戻すための、自分専用ホーム画面アプリ
（PWA）**です。スクロールを止めること自体が目的ではなく、止めた分の時間を
どこへ向けるかを自分で決めさせることが目的です。オンボーディングで最初に
「何のために時間を取り戻したいか」を尋ねるのはそのためで、以降の制限は
すべてその目標を守るための道具として働きます。
サーバーを持たず、データはすべて端末の中だけに置きます。

## できること

### スクロールの制限
- 左上のボタンでスクロールのON/OFFを切り替えます。OFFの間はページの物理スクロールが
  できません（タッチ・ホイールとも禁止）。モーダルの中身だけは例外的に動きます
- ONにするには「制限時間」「スクロールPIN」が要ります。Face ID / 指紋でも可
- 制限時間が来ると自動でOFFに戻ります
- 制限時間の選択肢は、設定から自由に追加・削除できます
- **制限時間はタップ一つのチップで選びます**（プルダウンではありません）。前回選んだ
  長さを覚えていて、次にONにするときは最初からそれが選ばれています。PINは4桁が
  揃った瞬間に自動で確定するので、選ぶ・打つだけで完了します。「毎回考えさせる」
  こと自体が抜け道を探させる方向に働くという考えから、迷う手間を削っています

### 最初のセットアップ
- 4ステップだったオンボーディングに、研究紹介の直後へ**「何のために時間を
  取り戻したいか」を書く5ステップ目**を追加しました（任意・後からでも足せます）。
  ここで書いたものはそのまま「頑張りたいこと」に入ります
- セットアップが終わった直後、普段の画面へ流す前に**一度だけ**「いま起きたこと」
  画面を挟みます。スクロールが物理的に動かないことを実際に触って確かめてもらい、
  この不便さが何のためにあるか（さっき書いた目標があればそれを名指しして）を
  伝えます。説明よりも先に、不便さそのものを体験してもらうのが狙いです

### 他のアプリの扱い
- 下部のドックに最大10個までアプリを置けます。候補から選ぶほか、任意のサイトを
  自分で追加できます。並び順・アイコンの大きさ・形・名前の表示も変えられます
- **スクロールOFFの間は、指定したアプリを開かせません**。対象は設定で選べます
  （既定はInstagram・Facebook・X・YouTube・TikTok・Threads）。アドレス欄への
  直接入力も同じ門を通ります
- ブロック画面からそのままスクロールをONにすると、**そのアプリが続けて開きます**
- **時間切れになると、開いたアプリのタブをこのアプリ側から閉じます**（設定で切替）
- 他のアプリを「同じ画面で開く」か「別タブで開く」かを選べます。前者は端末が
  このアプリから切り替わらず、後者は上記のタブを閉じる動作が使えます

### 簡易ブラウザ
- 検索（Bing）とアドレス入力。開いたページはタブとしてアプリ内に表示します
- **動画1本・投稿1件へのリンクは、アプリの中に表示します**。各サービスが配って
  いる埋め込み用アドレス（YouTube・Instagram・X）に変換して開くためです。
  フィード全体は表示できません（後述）
- 広告ブロック（既知の広告・トラッキングドメインへの遷移を止めるだけ）

### ひと息の待合室と本棚
- 何か見たい・開きたいものは、まず「待合室」で**待ってから**開くか本棚へしまうか決めます。
  URL・ファイル（画像・PDF・音声・動画など）のどちらも預けられます
- 待ち時間は相手によって変えています。**スクロールONを要求しているアプリは90秒、
  それ以外は25秒**、自分から押す「ひと息つく」は60秒です。何にでも一律に長く待たせると
  軽い用事まで面倒になり、アプリごと避けられてしまうためです
- 本棚は壁ごとに背表紙が並ぶ見た目で、優先度（高・中・低）と「済」の印を付けられます。
  済にしたものは元の壁から消えず、専用の「済」棚にもまとめて表示されます
- 本棚の中は検索できます（タイトル・URLを横断）
- **いつでも自分で本を追加できます**: 「＋ 本を追加」から題名（とリンクは任意）を
  打ち込むだけで棚に並びます。待合室で預かったものだけでなく、思いついたものを
  そのまま棚にしまえます
- **棚を丸ごと人に渡せます**: 名前を付けた棚を「共有」すると、その棚に入っている
  リンク付きの項目がリンク一つにまとまります（サーバーは使わず、リンクの中に
  中身を埋め込む方式です）。受け取った人がそのリンクを開くと、中身を確認してから
  「自分の本棚に追加」でき、既に持っている棚には一切触れません。自分の曲リストを
  人に見せられる音楽サービスのように、自分が選んだ題名の棚を人に見せられます
- 本棚の項目には**所要分数**を任意で付けられます。「12分で終わる」と分かっている
  ことは、実際に手を付けるかどうかの判断を大きく変えるため、休憩の提案や下記の
  週次振り返りに、選んだ分数の合計が表示されます
- **休憩のリマインド**: 一定の経過時間（既定30分）またはスクロール回数に達すると、
  どの画面にいても静かなバナー（音は出さず、対応端末では短い振動）が出て、
  何かを1つ差し出します。操作はブロックしません。スヌーズ（先送り）もできます
- **頑張りたいこと**: 設定からだけでなく、**待合室の画面からも直接**登録できます
  （「＋ 追加する」）。本棚に貯まるのは「あとで見る」と先送りしたものだけなので、
  それだけを勧めると気散じを別の気散じに替えるだけになりかねません。休憩では
  半分をこの「頑張りたいこと」に、4回に1回を本棚から、さらに4回に1回を下記の
  「あなたの辞書」に保存した言葉から差し出します。何も登録が無ければ段階的に
  フォールバックし、最後は画面から離れる小さな行動を提案します。本棚のおすすめ順は
  「自分の並び順」か「優先度順（高→中→低）」から選べます
- 頑張りたいことには**時間帯・曜日・所要分数・いつまで頑張るか（締切日）**を任意で
  付けられます。曜日は平日/休日の2択ではなく、月〜日から好きな組み合わせを選べます
  （例: 水曜だけ、月〜金だけ、土日だけ）。条件が具体的なほど実際に始めやすくなる
  ためで、休憩はいまに合うものから順に探します。条件を付けたせいで候補が消えない
  よう、合うものが無ければ段階的に緩めて必ず何かを差し出します。締切日を付けると、
  一覧に「残り5日」のように出ます
- 複数の「頑張りたいこと」が今に合うときは、**毎回くじ引きで**選びます。順番に
  出すと「次はこれ」と先読みできてしまい、本当にその気になったから選んだ、では
  なくなってしまうためです

### 自分との約束を守りやすくする仕組み
- **週に一度の振り返り**: 直近2週間に片付けたものを、数ではなく**題名で**並べます。
  本棚で「済」にしたものと、頑張りたいことを実際にやった記録の両方が対象です。
  所要分数を付けたものがあれば、その合計時間も添えて「これだけ自分で選んだ時間を
  使った」という収支として見せます。直近6週の週ごとの本数も棒で添えます
  （合計だけでは伸びも落ちも見えないため）。毎日出すと風景になるので自動表示は
  7日に一度だけですが、待合室の「片付いた」を押せばいつでも開けます
- **頭を冷やす時間**: 設定を**厳しくする**変更はその場で効きますが、**緩める**変更
  （休憩を切る・間隔を延ばす・スクロール回数を増やす・ゲート対象アプリを外す・
  この仕組み自体を切る）は**24時間待ってから**反映されます。待っている間は
  設定画面に一覧が出て、いつでも取り消せます。制限を決めるときの自分と、
  破りたくなったときの自分は同じ場所にいない、という前提の仕組みです
- **「もし〜なら、〜する」**: 落ち着いているうちに条件と行動を決めておくと、
  アプリが止められた画面でそのまま読み返されます
- ブロック画面では「ひと息預ける」を主action、「それでもONにする」は目立たない
  文字リンクにしています。抜け道は塞ぎませんが、押しやすくもしていません
- **他のアプリの共有ボタンから直接ここに送る**: PWAとしてホーム画面に追加した状態であれば、
  YouTube・Safari・その他のアプリの共有シートに「MyHome Browser」が候補として出るようになり、
  タップすると待合室に届きます（URL・テキスト・ファイルいずれも対応）。届いたものは
  他の預けものと同じく60秒の待合室を経由します
- **小さな祝福**: 本棚のものを「済」にした瞬間・辞書に言葉を足した瞬間・頑張りたいことを
  「やった」にした瞬間だけ、紙吹雪と一緒に一言添えます。無限スクロールの
  「次に何が来るか分からない」報酬に対抗できるのは、良い時間の使い方をしたという
  実感そのものだという考えからです。動きに敏感な設定（prefers-reduced-motion）では出しません

### あなたの辞書
- 調べた言葉を保存します。検索して開いたタブは検索語がそのままタブ名になり、
  ☆で見出し語として保存できます。手で追加することもできます
- 辞書の中を検索（言葉・意味メモ・URLを横断）
- 自分で作ったグループへ振り分け。並び順は「自分の並び順／五十音・アルファベット順／
  新しい順／古い順」から選べます
- **休憩でうんちくとしても差し出されます**: 保存した言葉の一つが、上記の休憩の
  提案先の一つになります。自分が既に「面白い」と思って拾った言葉だからこそ、
  無限スクロールの「次に何が来るか分からない」報酬に、質の違う面白さで対抗できる
  という考えからです。SNSへの接続を断ち切って独房に閉じ込めるのではなく、
  自分の興味そのものを差し出す仕組みです

### 記録と通知
- インサイト: アプリごとの滞在時間、スクロールをONにした回数と時間、1日の目標と達成
- 通知: スクロールの時間切れ1分前・時間切れ・タイマー終了・姿勢のリマインド・
  1日の上限超過。個別に切り替えられます。通知をタップするとこのアプリに戻ります
- **アプリを閉じていても通知したい場合**: 設定に「アプリを完全に閉じていても通知する」が
  任意で出ます（既定OFF）。これは`push-server/`（Cloudflare Workers + D1、別リポジトリ内の
  独立したサーバー）をデプロイして初めて使えます。デプロイしていなければトグル自体が
  出ません。上記5種類のうち、スクロール残り1分・時間切れ・タイマー終了・姿勢のリマインドの
  4つはこの方式に対応しますが、**1日の上限超過だけは対応できません**。これは「今日どれだけ
  使ったか」をその都度観測して初めて分かるもので、未来のある時刻を予約しておく形の通知
  とは性質が違うためです（サーバーを足しても解決しない制約です）。このサーバーに送られるのは
  「どの端末に」「いつ」「どんな文言を」送るかだけで、利用状況・辞書・本棚の中身などは
  一切含みません
- **通知の一発切り替え**: 左上のヘッダーにベルのアイコンが常時出ています。個別の種類は
  設定に残したまま、これを1回押すだけで通知を全部オン・全部オフにできます
- **匿名の利用ログをGoogle Sheetsに送りたい場合**: 通知とは別に、`push-server/`のデプロイと
  Google Sheetsの追加設定（`push-server/README.md`参照）が必要です。設定すると、
  アプリ内に個別のオン/オフはなく**自動的に確実に**送られます。「スクロールをONにした」
  「本棚の項目を済にした」といった、決まった名前の出来事だけをランダムな端末IDと
  一緒に送ります。検索語・辞書の中身・本棚のタイトル・URLなどは一切含みません。
  送信先はあなたが`GOOGLE_SHEET_ID`に指定したGoogle Sheetsで、これ以外の場所には
  送られません。送られる内容の全リストは`push-server/README.md`にあります

### 見た目
- 黒地に緑を差した配色、太めの見出し、余白を広めに取った構成が基調です
  （設定の配色プリセットから他の色にも変えられます）
- 本棚は木目調ではなく、暗い壁龕（アルコーブ）に光が落ちるような質感にしてあります。
  背表紙には円柱状の陰影と、上下二本の箔押し帯だけを差し色として加えています
- 本を開く・成し遂げたことを記録するといった意味のある操作には、押した瞬間の
  小さな動き（対応端末では振動も）を添えています。動きに敏感な設定
  （prefers-reduced-motion）では出しません

### そのほか
- アプリロック（PIN、秘密の質問、Face ID / 指紋）
- フォーカスタイマー（時間が来たらアプリをロックすることも可能）
- 配色・背景画像のカスタマイズ
- 8言語（英語・日本語・スペイン語・中国語・韓国語・フランス語・ドイツ語・ポルトガル語）

## 技術的な制約（重要）

これは通常のWebページ（PWA）です。Chromiumなどのブラウザエンジンを内蔵した
「本物のブラウザアプリ」ではないため、以下は**できません**。

- **フィード（Instagram・X・TikTok等のトップページ）をこのアプリの中に表示すること**
  はできません。これらは `X-Frame-Options: DENY / SAMEORIGIN` を返しており、
  他サイトの中で描画することをブラウザ側が拒否します。埋め込む側からは
  上書きできない仕組み（クリックジャッキング防止）です。
  ただし**各サービス公式の埋め込み用アドレスは拒否していない**ため、
  動画1本・投稿1件であればアプリ内に表示できます（実装済み）
- **開いた先のページのスクロールを止めること**はできません。スクロール禁止が効くのは
  このアプリ自身の画面内だけです。代わりに「開かせない」「時間が来たらタブを閉じる」
  という形で入口と出口を押さえています
- **端末にインストール済みのアプリ一覧を自動取得すること**はできません。ドックの
  候補は `app.js` の `APP_CANDIDATES` から選ぶ方式です（任意サイトの追加は可能）
- **アプリを完全に閉じた後に通知を出すこと**はできません。押し配りの通知（Web Push）
  にはサーバーが必要です。通知はこのアプリが裏で動いている間だけ届きます
- **他アプリの共有ボタンにMyHome Browserを出すには、ホーム画面への追加（PWAインストール）が必須**です。
  ブラウザでタブを開いているだけの状態では、OSの共有シートに候補として出てきません。
  また、共有シートにPWAが出るかどうかはOS・ブラウザ側の対応状況に左右されます。
  仕組み自体（`manifest.json` の `share_target` とService Workerでの受け取り）は
  Web標準どおりに実装し、Service Workerへの模擬POSTでは正しく届くことを確認しましたが、
  **この環境には実機が無く、実際のYouTube/Safari等の共有シートからの見え方・動作は
  確認できていません**。ホーム画面に追加したうえで、お使いの端末で一度お試しください

任意のサイトでもスクロール禁止を効かせたい場合は、ネイティブアプリ化が必要です。
構成・作業量・難所は `NATIVE_PLAN.md` にまとめてあります。その場合も、この画面
（HTML/CSS/JS）はほぼそのまま流用できます。

## アイコンについて

PWAインストール用アイコン（`manifest.json` の `icons` と `index.html` の
`<link rel="icon">` / `<link rel="apple-touch-icon">`）は、仮の単色プレース
ホルダー画像をdata URIとして直接埋め込んでいます。実際のロゴが決まったら、
192x192と512x512のPNG画像を用意して差し替えてください。

## ローカルでの動作確認方法

```bash
cd webapp
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。

`file://` で直接開くとService Workerが動かず、ホーム画面への追加が機能しません。
必ずこの方法か、任意の静的ホスティング経由でアクセスしてください。

スマホでの見た目を確認したい場合は、開発者ツールのモバイル表示を使うか、
同一ネットワーク内のスマホから `http://<PCのIPアドレス>:8000/` を開いてください。

## スマホのホーム画面に追加する

アプリ内の 設定 →「ホーム画面に追加する」に、お使いの環境に応じた手順が出ます。

1. スマホのブラウザで上記URLを開く
2. Safari: 共有 →「ホーム画面に追加」 / Chrome: メニュー →「アプリをインストール」
3. ホーム画面のアイコンから起動すると、アドレスバーの無い表示になります

通知はiOSの場合、**ホーム画面に追加済みのアプリでのみ**許可できます。

## データの保存場所

設定・辞書・記録・スクロールの状態は、すべて端末のブラウザの `localStorage` に
保存されます。サーバーには何も送信されません。

裏を返すと、**ブラウザのデータを消すか端末を変えると失われます。**
辞書を長く育てる場合は、書き出し機能の追加を検討してください（未実装）。
