# MyHome Browser（自分専用スクロール禁止ホーム画面）

スマホでの時間の浪費を減らすための、自分専用ホーム画面アプリ（PWA）です。
サーバーを持たず、データはすべて端末の中だけに置きます。

## できること

### スクロールの制限
- 左上のボタンでスクロールのON/OFFを切り替えます。OFFの間はページの物理スクロールが
  できません（タッチ・ホイールとも禁止）。モーダルの中身だけは例外的に動きます
- ONにするには「理由」「制限時間」「スクロールPIN」が要ります。Face ID / 指紋でも可
- 制限時間が来ると自動でOFFに戻ります
- 理由と制限時間の選択肢は、設定から自由に追加・削除できます

### 他のアプリの扱い
- 下部のドックに最大10個までアプリを置けます。候補から選ぶほか、任意のサイトを
  自分で追加できます。並び順・アイコンの大きさ・形・名前の表示も変えられます
- **スクロールOFFの間は、指定したアプリを開かせません**。対象は設定で選べます
  （既定はInstagram・Facebook・X・YouTube・TikTok・Threads）。アドレス欄への
  直接入力も同じ門を通ります
- ブロック画面からそのままスクロールをONにすると、**そのアプリが続けて開きます**
- **時間切れになると、開いたアプリのタブをこのアプリ側から閉じます**（設定で切替）
- 他のアプリを「同じ画面で開く」か「別タブで開く」かを選べます。前者は端末が
  このアプリから切り替わらず、後者は上記のタブを閉じる動作が使えます

### 簡易ブラウザ
- 検索（Bing）とアドレス入力。開いたページはタブとしてアプリ内に表示します
- **動画1本・投稿1件へのリンクは、アプリの中に表示します**。各サービスが配って
  いる埋め込み用アドレス（YouTube・Instagram・X）に変換して開くためです。
  フィード全体は表示できません（後述）
- 広告ブロック（既知の広告・トラッキングドメインへの遷移を止めるだけ）

### ひと息の待合室と本棚
- 何か見たい・開きたいものは、まず「待合室」で**60秒待ってから**開くか本棚へしまうか決めます。
  URL・ファイル（画像・PDF・音声・動画など）のどちらも預けられます
- 本棚は壁ごとに背表紙が並ぶ見た目で、優先度（高・中・低）と「済」の印を付けられます。
  済にしたものは元の壁から消えず、専用の「済」棚にもまとめて表示されます
- 本棚の中は検索できます（タイトル・URLを横断）
- **強制的な休憩**: 一定の経過時間（既定30分）またはスクロール回数に達すると、
  どの画面にいても本棚から1冊おすすめしてくる休憩画面が割り込みます。
  おすすめの順番は「自分の並び順」か「優先度順（高→中→低）」から選べます。
  スヌーズ（先送り）もできます
- **他のアプリの共有ボタンから直接ここに送る**: PWAとしてホーム画面に追加した状態であれば、
  YouTube・Safari・その他のアプリの共有シートに「MyHome Browser」が候補として出るようになり、
  タップすると待合室に届きます（URL・テキスト・ファイルいずれも対応）。届いたものは
  他の預けものと同じく60秒の待合室を経由します

### あなたの辞書
- 調べた言葉を保存します。検索して開いたタブは検索語がそのままタブ名になり、
  ☆で見出し語として保存できます。手で追加することもできます
- 辞書の中を検索（言葉・意味メモ・URLを横断）
- 自分で作ったグループへ振り分け。並び順は「自分の並び順／五十音・アルファベット順／
  新しい順／古い順」から選べます

### 記録と通知
- インサイト: アプリごとの滞在時間、スクロールをONにした回数と時間、1日の目標と達成
- 通知: スクロールの時間切れ1分前・時間切れ・タイマー終了・姿勢のリマインド・
  1日の上限超過。個別に切り替えられます。通知をタップするとこのアプリに戻ります

### そのほか
- アプリロック（PIN、秘密の質問、Face ID / 指紋）
- フォーカスタイマー（時間が来たらアプリをロックすることも可能）
- 配色・背景画像のカスタマイズ
- 8言語（英語・日本語・スペイン語・中国語・韓国語・フランス語・ドイツ語・ポルトガル語）

## 技術的な制約（重要）

これは通常のWebページ（PWA）です。Chromiumなどのブラウザエンジンを内蔵した
「本物のブラウザアプリ」ではないため、以下は**できません**。

- **フィード（Instagram・X・TikTok等のトップページ）をこのアプリの中に表示すること**
  はできません。これらは `X-Frame-Options: DENY / SAMEORIGIN` を返しており、
  他サイトの中で描画することをブラウザ側が拒否します。埋め込む側からは
  上書きできない仕組み（クリックジャッキング防止）です。
  ただし**各サービス公式の埋め込み用アドレスは拒否していない**ため、
  動画1本・投稿1件であればアプリ内に表示できます（実装済み）
- **開いた先のページのスクロールを止めること**はできません。スクロール禁止が効くのは
  このアプリ自身の画面内だけです。代わりに「開かせない」「時間が来たらタブを閉じる」
  という形で入口と出口を押さえています
- **端末にインストール済みのアプリ一覧を自動取得すること**はできません。ドックの
  候補は `app.js` の `APP_CANDIDATES` から選ぶ方式です（任意サイトの追加は可能）
- **アプリを完全に閉じた後に通知を出すこと**はできません。押し配りの通知（Web Push）
  にはサーバーが必要です。通知はこのアプリが裏で動いている間だけ届きます
- **他アプリの共有ボタンにMyHome Browserを出すには、ホーム画面への追加（PWAインストール）が必須**です。
  ブラウザでタブを開いているだけの状態では、OSの共有シートに候補として出てきません。
  また、共有シートにPWAが出るかどうかはOS・ブラウザ側の対応状況に左右されます。
  仕組み自体（`manifest.json` の `share_target` とService Workerでの受け取り）は
  Web標準どおりに実装し、Service Workerへの模擬POSTでは正しく届くことを確認しましたが、
  **この環境には実機が無く、実際のYouTube/Safari等の共有シートからの見え方・動作は
  確認できていません**。ホーム画面に追加したうえで、お使いの端末で一度お試しください

任意のサイトでもスクロール禁止を効かせたい場合は、ネイティブアプリ化が必要です。
構成・作業量・難所は `NATIVE_PLAN.md` にまとめてあります。その場合も、この画面
（HTML/CSS/JS）はほぼそのまま流用できます。

## アイコンについて

PWAインストール用アイコン（`manifest.json` の `icons` と `index.html` の
`<link rel="icon">` / `<link rel="apple-touch-icon">`）は、仮の単色プレース
ホルダー画像をdata URIとして直接埋め込んでいます。実際のロゴが決まったら、
192x192と512x512のPNG画像を用意して差し替えてください。

## ローカルでの動作確認方法

```bash
cd webapp
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。

`file://` で直接開くとService Workerが動かず、ホーム画面への追加が機能しません。
必ずこの方法か、任意の静的ホスティング経由でアクセスしてください。

スマホでの見た目を確認したい場合は、開発者ツールのモバイル表示を使うか、
同一ネットワーク内のスマホから `http://<PCのIPアドレス>:8000/` を開いてください。

## スマホのホーム画面に追加する

アプリ内の 設定 →「ホーム画面に追加する」に、お使いの環境に応じた手順が出ます。

1. スマホのブラウザで上記URLを開く
2. Safari: 共有 →「ホーム画面に追加」 / Chrome: メニュー →「アプリをインストール」
3. ホーム画面のアイコンから起動すると、アドレスバーの無い表示になります

通知はiOSの場合、**ホーム画面に追加済みのアプリでのみ**許可できます。

## データの保存場所

設定・辞書・記録・スクロールの状態は、すべて端末のブラウザの `localStorage` に
保存されます。サーバーには何も送信されません。

裏を返すと、**ブラウザのデータを消すか端末を変えると失われます。**
辞書を長く育てる場合は、書き出し機能の追加を検討してください（未実装）。
