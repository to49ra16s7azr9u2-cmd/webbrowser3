# MyHome Browser（自分専用スクロール禁止ホーム画面）

スマホでの時間の浪費を減らすための、自分専用ホーム画面アプリ（PWA）です。

## できること

- 左上にロゴ（`logo.png` を置くと自動的に表示されます。無ければ「LOGO」のプレースホルダーが出ます）
- 左上のボタンでスクロールのON/OFFを切り替え
  - OFFのときはページの物理スクロールができません（タッチ/ホイールともに禁止）
  - ONにするときは「理由」と「制限時間」を選択肢から選ぶ必要があります。選ばないとONにできません
  - 制限時間が来ると自動的にOFFに戻ります
  - 理由・制限時間の選択肢は右上の⚙️設定から自由に追加・削除できます
- 中央のバナーで4種類のコンテンツを切り替え表示
  - 関心のある分野 / 関心のない分野 / 世間のトップニュース / 友人の投稿
  - 「友人の投稿」はさらにInstagram / Facebook / Xのタブに分かれています
  - フォロー中リスト部分（`.following-list`）は、ページ全体がスクロール禁止中でもそこだけ独立してスクロールできます
- 下部に最大10個までアプリショートカットを設置（「アプリを編集」から候補リストの中から選択）
  - タップするとアプリのURLスキームで直接起動を試み、未インストールならWeb版にフォールバックします
  - 対象アプリに既にログイン済みならそのまま開くため、追加のログイン操作は不要です

## 技術的な制約（重要）

これは通常のWebページ（PWA）として作られており、Chromiumなどの本格的なブラウザエンジンを内蔵した「本物のブラウザアプリ」ではありません。そのため以下はできません。

- **任意の外部サイト（Google検索結果や知らないサイトなど）を開いてスクロール禁止を効かせること**はできません。スクロール禁止が効くのはこのアプリ自身の画面内だけです。外部サイトを見たい場合は、通常のブラウザで別途開いてください。
- **スマホにインストール済みのアプリ一覧を自動取得すること**はできません。下部のアプリショートカットは、あらかじめ用意した候補リスト（`app.js` の `APP_CANDIDATES`）から選ぶ方式です。
- **友人の投稿（Instagram/Facebook/X）は現状すべてサンプル(モック)データ**です。本物のSNSデータを表示するには、各社の公式API（Instagram Graph API / Facebook Graph API / X API）へのアプリ登録・審査・自分のOAuth認証が別途必要です。連携する際は `app.js` の `SAMPLE_FRIEND_POSTS` を実際のAPI呼び出しに差し替えてください。
- 同様に「関心のある分野」「トップニュース」なども `SAMPLE_FEEDS` のモックデータです。実際のニュースAPI/RSSと繋ぐ場合はここを差し替えます。

任意サイトでもスクロール禁止を効かせたい場合は、Android/iOSのネイティブアプリ（WebViewにJSを注入する方式など）が必要になります。その際も、このPWAの画面（HTML/CSS/JS）はほぼそのままネイティブアプリ内のWebViewとして流用できます。

## ロゴの差し替え

`webapp/logo.png` という名前の画像ファイルをこのフォルダに置くだけで、自動的にヘッダー左上に表示されます。

## アイコンについて

PWAインストール用アイコン（`manifest.json` の `icons` と `index.html` の `<link rel="icon">` / `<link rel="apple-touch-icon">`）は、仮の単色プレースホルダー画像をdata URIとして直接埋め込んでいます。実際のロゴが決まったら、192x192と512x512のPNG画像を用意し、そのdata URI（またはファイルパス）に差し替えてください。

## ローカルでの動作確認方法

```bash
cd webapp
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。スマホでの見た目を確認したい場合は、ブラウザの開発者ツールでモバイル端末エミュレーションを使うか、同一ネットワーク内のスマホから `http://<PCのIPアドレス>:8000/` にアクセスしてください。

## スマホのホーム画面に追加する

1. スマホのブラウザで上記URLを開く
2. Safari: 共有 → 「ホーム画面に追加」 / Chrome: メニュー → 「ホーム画面に追加」
3. ホーム画面のアイコンから起動すると、アドレスバーの無いアプリのような見た目（standalone表示）で開きます

## データの保存場所

理由・制限時間の選択肢、選択中のアプリ、現在のスクロール状態などはすべて端末のブラウザの `localStorage` に保存されます。サーバーには何も送信されません。
